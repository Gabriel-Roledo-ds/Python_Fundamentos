# Python Fundamentos — Algoritmos e Introdução à Computação

Exercícios da disciplina Algoritmos e Introdução à Computação, do curso
de Ciência de Dados da Faculdade de Tecnologia de Ourinhos (Fatec Ourinhos).

## Objetivo
Este repositório reúne exercícios resolvidos **sem uso de IA**, com o
propósito de treinar o raciocínio lógico e o pensamento computacional
desde a base. A complexidade dos desafios aumenta gradativamente
conforme novos exercícios são adicionados.

Além dos exercícios fornecidos pela faculdade, novos desafios serão
incluídos por iniciativa própria, ampliando a prática para além do
conteúdo formal do curso.

## Sobre
Estou em transição de carreira para Ciência de Dados / Análise de Risco
de Crédito, e este repositório documenta minha evolução prática com
Python, começando pelos fundamentos.
